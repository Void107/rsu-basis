# RSU Cost Basis Reconciler — 产品与开发指南

独立、本地优先的 RSU 成本基础核对与工作底稿工具。没有组织账号、企业邮箱、邀请或特定宿主要求。任何获得构建文件的用户都可以运行演示；产品维护者不接收用户的真实税务文档。

**当前为预览原型，不是已经支持真实报税任务的正式产品。** 真实券商文档的提取、校验与交付闭环尚未完成。独立产品定位不代表软件著作权归属已经经过法律认定。

## 产品边界

领域范围是美国税务居民、单税年、单券商的 RSU 成本基础底稿。产品不申报、不 e-file、不提供税务建议。ESPP、期权、多州分摊、wash sale、拆分与并购等不在当前支持范围内。范围外场景不得通过跳过校验继续交付。

内置合成案例无需真实税务资料。具体使用与构建方法见仓库根目录 README。

## 架构原则

1. 所有金额计算由确定性代码执行；模型不得决定金额或自行填补缺失字段。
2. 文档处理在设备本地执行，无上传后端、遥测或业务浏览器存储。
3. 缺少必需数据或未通过必要检查，停止交付并说明原因。
4. 计算结果应保留来源、规则和检查状态；导出文件本身可能包含敏感资料。
5. 核心引擎不依赖 Agent 或表格编辑器。未来适配器必须保留同样的验证和数据边界。

## 技术栈

React、TypeScript、Vite 单文件构建、PDF.js 文本提取、Decimal.js 金额计算、ExcelJS 导出、Vitest 与 fast-check 验证。无后端。

## 开发与发布阶段

| 阶段 | 工作 | 验收依据 |
|---|---|---|
| P-1 发布准备 | 明确维护主体、贡献来源和依赖许可 | 按实际分发方案检查，不预设与任何组织的关系 |
| P0 数据可得性 | 确认字段含义、行粒度、文本层和合计锚点 | 公开样本与用户自愿提供的非敏感结构信息 |
| P1 引擎 | 确定性计算与输入验证 | 独立样例验算、属性测试、非法输入与业务边界测试 |
| P2 提取 | 支持明确的券商版式与税年 | 字段映射、来源回比、合计核对和失败分支验证 |
| P3 导出 | 生成底稿并回读校验 | 引擎与输出一致，实际编辑器兼容性验证 |
| P4 本地打包 | 单文件运行、诊断报告与使用引导 | 真实浏览器验证、断网测试、无存储/外发检查 |
| P5 用户预览 | 自愿招募符合适用范围的用户 | 本机任务完成情况、失败路径与复核反馈 |

阶段表示验收要求，不表示这些工作均已完成。已有引擎、提取基础设施、导出与演示 UI；真实文件全流程仍待验证。完整 CI 通过不替代真实版式或税务语义验证。

## 预览与正式发布

预览资格由产品支持范围决定，与用户雇主、团队或邮箱域名无关。用户可自行构建；发布方提供的构建文件应注明版本、校验哈希、支持范围和已知限制。

正式发布、收费或新增云端处理之前，重新评估实际数据流、支持流程、依赖许可及适用要求。不得继续沿用与实际实现不符的本地隐私承诺。
