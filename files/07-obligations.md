# 07 — 独立产品的发布与数据处理检查

本文件是工程与运营检查清单，不是法律意见，也不判定软件权属。按实际维护主体、用户地区、分发方式、收费模式与数据流核实适用要求。

## 1. 发布主体与贡献来源

确认维护负责人、代码与素材的来源、依赖许可、第三方样本引用和分发权利。涉及合同或权属疑问时取得专业意见。产品不以任何雇主、团队或组织身份作为使用资格，不暗示组织背书。

## 2. 本地预览的数据边界

### 2.1 不接收真实税务材料

用户在自己设备上处理 PDF；维护者不收取 W-2、1099-B、账户资料或含敏感信息的结果底稿。反馈使用不含个人数据的结构描述和诊断报告。

### 2.2 不自动回传

不启用遥测、崩溃上报或云端文档存储。用户自行查看报告，再决定是否分享。报告字段采用白名单，不记录姓名、账号、金额、文件名、原文或文件哈希。

### 2.3 数据边界变化

当前不实现云端模型回退。如果未来增加云处理，先明确接收方、处理目的、字段、保存时间和删除机制，再根据适用要求设计告知与授权。不得把本机模式的隐私声明直接用于云端模式。

### 2.4 文件保存与分享

真实资料不进入源码仓库。导出的 Sources 与隐藏台账可能含敏感字段；用户应在分享前核对范围。隐藏 sheet 不等于加密或脱敏。

## 3. 模型与计算

当前没有模型调用。未来模型只能协助提取候选字段和解释结果，不得替代确定性算术、补造缺失值或把未执行的检查标记为通过。

### 3.1 LLM 回退状态

L3 为未启用的未来设计，必须在数据处理方案与独立验证就绪后评估。拒绝云处理不应影响已支持的本地功能。

## 4. 变更触发表

| 变化 | 发布前检查 |
|---|---|
| 分发新预览版本 | 版本、构建哈希、范围、已知限制、安装与支持说明 |
| 扩大税年/券商/交易类型 | 输入结构、规则版本、独立样例与失败路径 |
| 提供正式服务或收费 | 服务条款、责任范围、隐私说明及实际适用要求 |
| 新增联网或远程模型 | 数据接收方、授权、留存、删除、日志与跨工具传播 |
| 接入 Agent/云表格 | 最小权限、输入版本、重复调用、结果回读与分享边界 |
| 接收第三方贡献 | 贡献来源、许可、测试与敏感资料检查 |

不要从“免费”“本地”或“预览”推断无需任何发布审查，也不要从收费自动推断某项法律必然适用。

## 5. 发布验收

计算与导出验证通过；真实浏览器流程测试完成；支持范围准确；无真实税务数据进入仓库；发布者具备分发权限；报告和隐私说明与实际行为一致。

当前原型未完成真实券商文档全流程，不得宣传为正式报税服务。

## 6. 用户支持

错误提示应包含可执行的下一步。记录失败类型与软件版本，不要求用户发送原文件。误收到敏感材料时，按适用的数据处理与事件响应流程隔离处理，不纳入测试库。

## 7. 复查节奏

每次扩大范围、引入云服务或改变分发方式时重新检查本清单，并保存验收记录。
